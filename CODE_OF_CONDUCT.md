# Code of Conduct

This project adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct.

## Enforcement

Report unacceptable behavior privately to the maintainer via GitHub, using the repository's
private reporting channel (**Security** tab → **Report a vulnerability**) or by contacting
[@melnikaite](https://github.com/melnikaite). Reports are handled confidentially.
